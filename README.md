**Key Learnings / Best Practices**

-> Use a mix of uppercase, lowercase, digits, and special symbols.
-> Keep the password at least 12–16 characters long.
-> Avoid using personal information (like names, birthdays).
-> Replace predictable patterns like “123” or “@123” with random strings.
-> Consider passphrases (e.g., “T!m3_to$ecur3#Y0uR_D@t@”) for both strength and memorability.
-> Don’t reuse passwords across multiple accounts.
-> Enable MFA (Multi-Factor Authentication) for additional protection.
-> Use a password manager to securely store and generate strong passwords.


**Common Password Attacks**

Brute Force Attack	-> Tries every possible combination until the correct one is found.

Dictionary Attack	-> Uses common words or leaked password lists to guess passwords.

Phishing	-> Tricks users into revealing passwords using fake websites or messages.

Keylogging	-> Records keystrokes to capture passwords.


**How Password Complexity Affects Security**

->Longer passwords exponentially increase the number of possible combinations, making brute-force attacks harder.

->More character variety (uppercase, lowercase, digits, symbols) increases entropy, making dictionary attacks less effective.

->Randomness ensures unpredictability, reducing success rates of automated guessing attacks.




*Questions:*

1. What makes a password strong?

A combination of length, complexity, randomness, and uniqueness.


2. What are common password attacks?
   
Brute force, dictionary, phishing, and keylogging attacks.


3. Why is password length important?

Longer passwords drastically increase the number of possible combinations, making them harder to crack.


4. What is a dictionary attack?

It uses a list of common or known passwords to guess the correct one.


5. What is multi-factor authentication (MFA)?

It adds an extra security layer requiring additional verification beyond the password.


6. How do password managers help?

They securely store and generate strong, unique passwords for each account.


7. What are passphrases?

Longer combinations of random words or phrases that are easier to remember but harder to crack.


8. What are common mistakes in password creation?

Using personal info, short passwords, common words, or reusing passwords across sites.
